*** Storage ***
The storage of AImageLab-SRV is shared between all nodes. There are three positions that you can use:
- /homes/<username>, personal and resilient area which should be used for storing code, logs and vital data
- /work/<project>, project-level and high-capacity area which should be used to store datasets and checkpoints

Quotas can be active on all positions. In particular, your home folder has a quota of 100 GB. To check your usage, quota, and active positions run "squota" from the login node.

To view the project(s) you are assigned to, please log in at: https://ailb-web.ing.unimore.it/coldfront/.

*** Production resources ***
Beyond development, AImageLab-SRV has a set of GPU-powered nodes administered by SLURM, which deals with queue management and job monitoring.

For those who have never used SLURM, here is a 101 guide:
- Request an interactive job with a GPU:
srun --gres=gpu:1 --pty bash
- Run a python script with two GPUs:
srun --gres=gpu:2 python script.py
- Execute jobs and job arrays in batch mode: see the sbatch command
- Monitor the status of the queues: see the squeue command
- Delete a job: see the scancel command

It is advisable to take a quick look at the SLURM documentation in order to appreciate its functionality and to have some pointers to the documentation before starting.
